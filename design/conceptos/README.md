# Conceptos de web para la galería

Webs de concepto (marcas inventadas, no son clientes) que se usan como capturas en la sección
«Diseño web» de la home mientras no haya proyectos reales que enseñar.

Generar las capturas (escritorio 1440x900 y móvil 390x844) en `prototipo/img/webs/`:

    node design/conceptos/shoot.js

Cuando haya proyectos reales, sustituir las imágenes de `prototipo/img/webs/` y los textos de la galería.
